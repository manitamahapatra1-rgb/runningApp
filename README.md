# runningApp
*(working title — yeah, I know this isn't creative at all)*

An AI-personalized running training plan generator. Takes a runner's recent 
race time, current weekly mileage, and goal race, then generates a periodized 
training plan that adapts week-to-week based on real training data pulled 
automatically from Strava.

## Why this is more than an API wrapper

The plan itself is generated by a deterministic, rules-based periodization 
engine (Jack Daniels VDOT paces, structured mileage progression, adaptive 
recovery weeks) — not by asking an LLM to invent training advice. The LLM's 
job is narrower and more specific: parsing subjective runner feedback 
(soreness, pain, effort) into structured signals, and explaining plan 
adjustments in plain language. The rules engine, not the LLM, always makes 
the final call on any change to mileage or workouts.

## Tech stack

- **Backend:** Python, FastAPI, SQLAlchemy
- **Frontend:** React (Vite), Tailwind CSS
- **AI orchestration (planned):** LangChain / LangGraph
- **Data source (planned):** Strava API (OAuth, automatic activity sync)
- **Database:** SQLite (dev) → PostgreSQL/Supabase (prod, planned)

## Setup

**Backend:**
```bash
python -m venv venv
.\venv\Scripts\Activate.ps1  # Windows
pip install fastapi uvicorn sqlalchemy
uvicorn app:app --reload
```
Runs at `http://localhost:8000`.

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```
Runs at `http://localhost:5173`. Requires the backend running simultaneously.
